# Back Knee Strengthening - Prompt

Apply `strength/common-rules.md`.

Confirm the prescribed ankle weight and hand support while the user stands tall facing a stable chair. Ask the user to bend the working knee, bringing the foot toward the buttocks, then return slowly to the starting position. Follow the prescribed side sequence.

A valid repetition shows knee flexion and controlled extension return while the thigh remains comparatively vertical, the pelvis stays stable, and the trunk remains upright. Prioritize correction when the whole thigh swings backward, the hip flexes, the trunk leans forward, the support does not match the prescription, or the foot drops rapidly. Count only a complete bend-return cycle.
