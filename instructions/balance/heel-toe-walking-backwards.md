# Heel-Toe Walking Backwards - Prompt

Apply `balance/common-rules.md`.

Confirm a clear path near a wall or countertop, eyes ahead, and the prescribed support. Ask the user to place one foot directly behind the other and continue backward in a near-straight heel-to-toe sequence for the prescribed number of steps. Guide the turn separately before the return segment.

A valid step combines backward body displacement with near-tandem foot placement, controlled speed, correct support, and the prescribed direction. Count backward tandem steps only; exclude turning, adjustment, and recovery steps. Prioritize correction for looking continuously down, converting the task into ordinary wide-base backward walking, releasing required support, or instability.
