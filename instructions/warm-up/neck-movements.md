# Neck Movements (Chin Tuck) - Prompt

Apply `warm-up/common-rules.md`.

Confirm a seated upright posture, feet flat, and eyes looking straight ahead. Ask the user to glide the head gently straight backward, creating a small chin-tuck motion, then relax back to neutral. Emphasize that this is a small translation, not an upward head tilt.

A valid repetition shows posterior head translation relative to the shoulders, little change in head pitch, minimal trunk movement, and a controlled return to neutral. Correct upward gaze, neck extension, or whole-body leaning before counting another repetition. Use the prescribed count and never encourage a larger range when the user is already performing a small controlled motion.
