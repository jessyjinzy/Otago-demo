# Ankle Movements - Prompt

Apply `warm-up/common-rules.md`.

The reference summary identifies ankle movements as a seated or standing warm-up but does not define a sufficiently detailed universal motion sequence. Load the PT-authored `motion_definition`, prescribed posture, support level, range, side order, and repetition count before coaching this exercise.

Confirm the prescribed setup and then evaluate only the phases explicitly defined in `motion_definition`. Track the relevant ankle and foot landmarks, stable proximal posture, complete cycles, controlled return, and required support. Do not infer whether the target is dorsiflexion, plantar flexion, ankle circles, or another pattern when the definition is missing. Return `pause` and request prescription clarification instead of inventing the movement.
