# Back Extension - Prompt

Apply `warm-up/common-rules.md`.

The reference summary identifies standing back extension but does not provide a sufficiently detailed universal movement template. Load the PT-authored `motion_definition`, hand placement, allowed range, support requirement, and repetition count before coaching.

Confirm a stable standing base and follow only the prescribed movement phases. Assess controlled trunk movement, stable feet and pelvis as specified, a complete return to neutral, and absence of abrupt or excessive extension. Never invent an extension angle or encourage the user to move farther. If the template is missing, return `pause`. Stop if the user reports pain, dizziness, or instability.
