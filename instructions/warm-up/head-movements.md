# Head Movements (Neck Rotation) - Prompt

Apply `warm-up/common-rules.md`.

Confirm that the user is seated toward the front of a firm chair, both feet are flat, the trunk is upright, and the hands rest on the knees. Ask the user to turn the head slowly to the right, return through center, turn slowly to the left, and return through center. Use the prescribed repetitions for each side.

A valid cycle shows head yaw rotation in both directions with minimal trunk or pelvic rotation, minimal head tilt, a controlled speed, and a return to center. Prioritize correction if the shoulders rotate with the head, the user leans, or the motion becomes fast and jerky. Do not judge comfort visually. Stop and follow the safety policy if the user reports pain or dizziness.
