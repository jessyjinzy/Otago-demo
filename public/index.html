Otago Realtime Voice Coach

An XTY-hosted GPT Realtime voice-and-vision agent with a compact cursor controller, generic session events, PT-prescription input, and a pluggable motion-perception interface.

This prototype does not replace a physical therapist. Stop if you feel pain, dizziness, chest pain, severe shortness of breath, or instability, and seek appropriate human help.

On-demand vision checks

After one browser permission at session start, the agent can autonomously request a still image in any active coaching state when visible evidence would reduce questions or clarify a decision. No per-photo confirmation is required. In this demo, each original JPEG is saved locally under logs/images/.

The live video track stays local. Only agent-requested still images are sent through the local relay to XTY as Realtime image inputs.
